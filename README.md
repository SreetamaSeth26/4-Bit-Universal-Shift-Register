# 4-Bit Universal Shift Register

A synthesizable **4-bit Universal Shift Register** implemented in Verilog, complete with a testbench for simulation and waveform dumping.

---

## Overview

This project implements a **synchronous 4-bit universal shift register** with four selectable modes: hold, shift right, shift left, and parallel load. It is driven by a clock and supports synchronous reset.

---

## Module: `univ`

### Ports

| Port    | Direction | Width  | Description                        |
|---------|-----------|--------|------------------------------------|
| `clk`   | Input     | 1-bit  | Clock signal (positive edge triggered) |
| `reset` | Input     | 1-bit  | Synchronous active-high reset      |
| `sel`   | Input     | 2-bit  | Mode select                        |
| `sin_r` | Input     | 1-bit  | Serial input for right shift       |
| `sin_l` | Input     | 1-bit  | Serial input for left shift        |
| `d`     | Input     | 4-bit  | Parallel data input                |
| `q`     | Output    | 4-bit  | Register output                    |

### Operation Modes

| `sel` | Mode           | Behaviour                            |
|-------|----------------|--------------------------------------|
| `2'b00` | Hold         | Output retains its current value     |
| `2'b01` | Shift Right  | MSB ← `sin_r`, LSBs shift right     |
| `2'b10` | Shift Left   | LSB ← `sin_l`, MSBs shift left      |
| `2'b11` | Parallel Load| `q` ← `d`                           |

> Reset is **synchronous** and sets `q` to `4'b0000` on the next rising clock edge when `reset = 1`.

---

## Testbench: `tb`

The testbench exercises all four modes in sequence:

1. **Reset** — asserts `reset` for 10 ns to clear the register
2. **Parallel Load** (`sel = 2'b11`) — loads `d = 4'b1011` into `q`
3. **Hold** (`sel = 2'b00`) — verifies output is retained
4. **Shift Right** (`sel = 2'b01`) — shifts in `sin_r = 1` from the MSB
5. **Shift Left** (`sel = 2'b10`) — shifts in `sin_l = 0` from the LSB

Waveform output is written to `dump.vcd` and can be viewed in the EDA Playground waveform viewer.

## Simulation — EDA Playground

This project was simulated using [EDA Playground](https://www.edaplayground.com/).

**Settings used:**

- Simulator: **Icarus Verilog** (under the Yosys + Icarus Verilog suite)
- Language: **Verilog**
- Testbench + Design: pasted into the respective editor panes

**Steps:**

1. Open [edaplayground.com](https://www.edaplayground.com/) and log in.
2. Paste `tb` into the **Testbench** pane and `univ` into the **Design** pane.
3. Under **Tools & Simulators**, select **Icarus Verilog**.
4. Check **Open EPWave after run** to view the waveform.
5. Click **Run**.

The `$dumpfile` and `$dumpvars` calls in the testbench automatically generate `dump.vcd`, which EPWave loads for signal inspection.

## Synthesis — Yosys (macOS Terminal)

This design can be synthesized locally using [Yosys](https://yosyshq.net/yosys/) on macOS.

**Install via Homebrew:**

```bash
brew install yosys
```

**Synthesize:**

```bash
yosys -p "read_verilog univ.v; synth; show" univ.v
```

Or use a Yosys script for a cleaner flow:

```bash
# synth.ys
read_verilog univ.v
hierarchy -top univ
synth
write_json univ.json
```

```bash
yosys synth.ys
```

This produces a gate-level netlist. The `show` command (requires Graphviz) renders the synthesized circuit as a schematic in your browser.
